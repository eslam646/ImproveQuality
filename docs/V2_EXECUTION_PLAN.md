# خطة تنفيذ Support Hub V2

## قاعدة العمل

- التطوير يتم على فرع `v2-development` فقط.
- لا تُنفذ Migration على Supabase Production قبل إنشاء Staging ونسخة احتياطية.
- الدمج إلى `main` والنشر إلى Cloudflare يتمان بعد اختبار وقبول كل مرحلة.

## المرحلة الحالية: Foundation

1. اعتماد مواصفات V2.
2. إنشاء Migration إضافية لا تحذف البيانات الحالية.
3. تجهيز نماذج الأنواع والصلاحيات ودورة الحالات.
4. إنشاء Staging منفصل.
5. اختبار Migration على نسخة بيانات تجريبية.

## بوابات الجودة قبل الإنتاج

- TypeScript بلا أخطاء.
- اختبارات صلاحيات الأدوار.
- اختبار كل انتقال حالة في الخادم.
- اختبار الإيميلات في وضع Log/Staging.
- اختبار رجوع Migration أو استعادة Backup.
- موافقة صاحب النظام على الواجهة والسلوك.
